# Systems To Build | Static Site Proposal

This public repository previously contained only a README and MIT license. The proposed branch adds an accessible, dependency-free **draft** public-facing site for Systems To Build.

## Scope

- Provides a high-level description of a proposed capability-oriented work-system architecture.
- Uses no personal name, employer information, third-party analytics, contact collection, cookies, or unverified production claims.
- Introduces semantic HTML, keyboard focus styling, responsive layout, reduced-motion support, and Node source checks.
- GitHub Pages was not enabled at the start of this work. Creating a static index.html does NOT publish the site.

## Run Locally

Serve the repository directory using any static HTTP server. Run npm test on Node 20+ to execute structural checks. Review manually using keyboard navigation and an accessibility auditing tool.
